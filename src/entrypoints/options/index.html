    Local HTTP bridge for programmatic import (default port 3002). Must be running for import to work; everything else runs locally in the extension.

    About

    Citation Nexus detects academic citations and English-language science concepts on web pages and lets you import or copy them. The full content script, pattern registry, and bridge protocol are documented in the docs/ folder.
